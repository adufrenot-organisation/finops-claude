# FinOps V103 — duplication

## Pré-simulation nominative
Le bouton **Dupliquer** recopie la fiche, ses équipes, ses ressources et leurs plans/affectations. L’auteur de la copie est toujours l’utilisateur connecté. Les droits supplémentaires ne sont pas recopiés : la copie est privée par défaut (auteur + Owner).

## Simulation / scénario
Le bouton **Dupliquer** dans la liste des scénarios crée une copie du scénario et de toutes ses allocations budgétaires. Les pré-simulations ne sont pas dupliquées.

Aucune migration Grist ni réconciliation ACL n’est nécessaire.
