# V80 — Coût équivalent annuel par domaine par défaut

Dans la Synthèse d'un scénario :

- le **coût équivalent annuel** est désormais affiché pour **chaque domaine**, qu'il existe ou non une pré-simulation ;
- il apparaît dans la vue budgétaire par domaine et dans l'en-tête de chaque détail de domaine ;
- définition : coût d'achat des licences ramené sur 12 mois ;
- le détail **par équipe** n'est affiché que si une pré-simulation enregistrée du domaine contient effectivement des équipes et des ressources ;
- dans ce cas, le coût équivalent annuel est également ventilé par équipe.

La présence de services n'est pas nécessaire pour afficher le coût équivalent annuel du domaine. Les services ne conditionnent que le niveau de détail ROI.
