# FinOps IA — V7 interface

Cette version part de la V5 multi-fournisseurs/ROI et modifie uniquement l'ergonomie du widget.

## Changements

- menu gauche rétractable avec mémorisation de l'état dans le navigateur ;
- largeur réduite à 74 px quand le menu est replié ;
- un seul bouton **Enregistrer les modifications** au-dessus de chaque tableau éditable ;
- l'enregistrement envoie toutes les lignes du tableau dans une seule action Grist ;
- Simulation conserve la suppression ligne par ligne (`×`) ;
- création d'une allocation et création d'un scénario restent des actions unitaires ;
- écrans concernés : Simulation, ROI / Baseline N-1, Scénarios, Fournisseurs & offres, Domaines, Droits utilisateurs.

Aucune migration Grist n'est nécessaire pour cette évolution d'interface.
