# FinOps multi-fournisseurs — V8

Évolutions UI :
- menu gauche toujours rétractable ;
- les éléments du menu peuvent être réordonnés à la souris par glisser-déposer ;
- bouton **Enregistrer l’ordre** pour mémoriser la disposition ;
- bouton **Ordre par défaut** pour revenir à l’ordre standard ;
- la configuration est enregistrée dans le stockage local du navigateur ;
- l’ordre sauvegardé est restauré automatiquement à chaque chargement ;
- si un profil n’a accès qu’à une partie du menu, seuls les éléments autorisés sont affichés et réordonnés.

Aucune migration Grist n’est requise pour cette évolution.
