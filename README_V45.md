# FinOps V45 — Menu User / Admin

## Évolutions

- La rubrique **User** est ouverte par défaut.
- La rubrique **Admin** est fermée par défaut.
- Le choix d’ouverture/fermeture reste mémorisé localement après la première interaction de l’utilisateur.
- Une rubrique n’est rendue dans la barre latérale que si elle contient au moins un item réellement visible pour le rôle courant.
- Le classement reste automatique : `Utilisateurs autorisés` → **User**, `Owner uniquement` → **Admin**.

Aucune migration Grist n’est nécessaire.
