# FinOps V107 — message ROI global allégé

Quand le ROI global est incomplet, l'écran et l'export HTML n'affichent plus
la liste détaillée des domaines/services manquants.

Restent uniquement :
1. `ROI global incomplet — X / Y périmètre(s) renseigné(s)`
2. l'explication indiquant que tous les domaines/services doivent avoir RH N-1 et RH N.

Aucune migration Grist ni réconciliation ACL.
