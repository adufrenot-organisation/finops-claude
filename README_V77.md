# V77 — Synthèse HTML : tableaux centrés

Dans le rapport HTML de la Synthèse et dans le détail d'un scénario :

- en-têtes de tableaux centrés ;
- contenu des cellules centré ;
- colonnes numériques centrées également ;
- alignement vertical centré ;
- tableaux de détail par domaine, par offre et par équipe uniformisés.

La modification cible le rendu HTML / impression afin de ne pas modifier l'ergonomie des tableaux de saisie de l'application FinOps.
