# V89 — ROI domaine horizontal

Dans le détail d'un domaine, le bloc ROI est maintenant présenté horizontalement,
dans le même style que la « Lecture économique du scénario ».

Ordre des KPI :
- RH N-1
- RH N
- Économie RH
- Coût annuel licences
- Gain net annuel
- ROI / gain %

Chaque KPI occupe une colonne avec séparateurs verticaux, libellé au-dessus et montant en dessous.
Les valeurs négatives restent en rouge et le ROI conserve une mise en évidence discrète.

Cette présentation est appliquée :
- dans le détail de scénario dans l'application ;
- dans `Ouvrir en HTML` ;
- dans le rapport HTML multi-scénarios.

Aucune migration Grist supplémentaire n'est nécessaire.
