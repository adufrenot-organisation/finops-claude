# FinOps multi-fournisseurs — V9

- ajout d’un bouton **Renommer les menus** dans la zone de configuration du menu gauche ;

- bouton **Libellés par défaut** pour réinitialiser les noms ;
- compatible avec l’ordre personnalisé et le menu rétractable des V7/V8.
