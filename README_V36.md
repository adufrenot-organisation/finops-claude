# FinOps V36 — Synthèse visuelle et impression

La page **Synthèse** devient le point d'entrée de comparaison et d'impression.

- Les scénarios cochés pilotent la synthèse.
- Les cartes scénarios sont cliquables.
- Chaque carte présente budget USD/EUR, licences, domaines, offres et répartition Fixe/Variable.
- Un clic ouvre une grande popup de détail.
- Le détail est regroupé par domaine et affiche fournisseur, offre, licences, engagement, mois facturés, coûts fixes, coûts variables et total.
- `Imprimer le détail` imprime le scénario ouvert.
- `Imprimer la synthèse` imprime uniquement les scénarios actuellement cochés, avec une première partie synthétique puis les détails de chaque scénario.
- Impression optimisée A4 paysage.

Aucune migration Grist n'est nécessaire.
