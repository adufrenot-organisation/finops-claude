# FinOps V31 — Filtres Scénarios dans la grille

Modifications demandées sur l'écran **Scénarios** :

- suppression de la dropdown globale `Scénario` en haut de l'écran ;
- suppression du bouton `Actualiser` en haut de l'écran ;
- ajout d'une dropdown **Scénario** directement dans la zone de filtres de la grille ;
- conservation de la recherche plein texte ;
- conservation des filtres Année et Statut ;
- conservation du bouton Réinitialiser et du compteur de résultats.

Important : le sélecteur global de scénario reste présent sur les écrans qui en ont besoin
(Simulation, Dashboard, ROI, Synthèse, etc.). Il est seulement masqué sur l'écran Scénarios.

Aucune migration Grist n'est nécessaire.
