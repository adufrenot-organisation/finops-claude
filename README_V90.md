# V90 — Titre ROI dans chaque détail Domaine

Dans chaque détail de domaine de la Synthèse, le bloc ROI horizontal est désormais précédé de :

- `ROI ANNUEL`
- `Lecture économique du domaine`

La présentation est identique dans :
- le détail du scénario dans l'application ;
- `Ouvrir en HTML` ;
- le rapport HTML multi-scénarios.

Le bloc horizontal conserve :
RH N-1 · RH N · Économie RH · Coût annuel licences · Gain net annuel · ROI / gain %.

Aucune migration Grist supplémentaire n'est nécessaire.
