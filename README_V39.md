# FinOps V39 — détail limité aux domaines budgétaires

Dans le détail d’une carte scénario et dans les impressions, seuls les domaines qui contribuent réellement au budget sont affichés.

Une allocation est considérée comme budgétaire dès qu’elle porte un coût fixe, un coût variable ou un total non nul. Les domaines ne contenant que des allocations à 0 sont masqués.

La Synthèse imprimée et le détail à l’écran utilisent exactement la même règle.

Aucune migration Grist n’est nécessaire.
