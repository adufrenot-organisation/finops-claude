# V76 — Synthèse : licences par équipe et par offre

Dans `Synthèse > Voir le détail > Détail par domaine`, la répartition issue de la pré-simulation affiche maintenant :

- Équipe
- Fournisseur
- Type d'offre
- Nombre de licences
- Budget réparti USD
- Budget réparti EUR
- Part du budget du domaine

Un second niveau affiche le total par équipe, toutes offres confondues :
- Nombre total de licences de l'équipe
- Budget total réparti de l'équipe

La règle de ventilation budgétaire reste celle de la V75 :
pour chaque offre du scénario, le budget complet de l'offre est réparti entre les équipes au prorata des licences nominatives de cette offre dans la pré-simulation.
