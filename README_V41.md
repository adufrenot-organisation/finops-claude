# FinOps V41 — Rapport HTML autonome

Ajout dans le détail d’un scénario de Synthèse :
- bouton **🌐 Ouvrir en HTML** ;
- ouverture du rapport dans un nouvel onglet navigateur ;
- rapport autonome avec les mêmes données que le détail/impression ;
- bouton **🖨 Imprimer / PDF** ;
- bouton **💾 Enregistrer le fichier HTML** ;
- nom de fichier généré automatiquement : `FinOps_<scenario>_AAAA-MM-JJ.html`.

Le rapport HTML conserve uniquement les domaines qui contribuent réellement au budget, comme le détail et l’impression.

Aucune migration Grist n’est nécessaire.
