# FinOps V40 — responsive / 100 % zoom

Objectif : rendre l'application confortable à 100 % de zoom navigateur.

Principales évolutions CSS :
- sidebar plus compacte selon la largeur disponible ;
- cartes et KPI en grilles adaptatives ;
- bandeau supérieur qui se replie proprement ;
- filtres Scénarios responsives ;
- tableaux limités à leur conteneur avec scroll horizontal local si nécessaire ;
- popup scénario presque pleine largeur ;
- passage automatique à une sidebar icône vers 900 px ;
- fallback mobile avec navigation horizontale.

Aucune migration Grist n'est nécessaire.
