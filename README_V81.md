# V81 — ROI dans le détail de scénario

Le détail d'un scénario dans la Synthèse affiche désormais le ROI directement.

## Niveau scénario
- Coût N-1
- Coût équivalent annuel
- Coûts supprimés
- Nouveau coût annuel
- Économie annuelle
- Taux d'économie

## Niveau domaine
Chaque carte Domaine affiche :
- Coût équivalent annuel
- Coût N-1
- Coûts supprimés
- Nouveau coût annuel
- Économie annuelle
- Économie %

## Niveaux conditionnels
- Le détail par équipe n'apparaît que si une pré-simulation enregistrée du domaine contient effectivement des équipes et des ressources.
- Le niveau Service reste conditionné à la présence de services dans cette pré-simulation.
- L'onglet ROI reste l'écran de saisie des références N-1 et coûts supprimés.
