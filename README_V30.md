# FinOps V30 — Recherche et filtres sur les scénarios

L'écran **Scénarios** dispose maintenant d'une barre de recherche et de filtres.

Fonctions :
- recherche plein texte sur Nom, Année, Statut et Commentaire ;
- filtre par Année ;
- filtre par Statut ;
- compteur `X scénario(s) affiché(s) sur Y` ;
- bouton Réinitialiser ;
- conservation du bouton `+ Nouveau` et de l'enregistrement groupé ;
- les brouillons nouvellement créés restent visibles même lorsqu'un filtre est actif.

Aucune migration Grist n'est nécessaire.
