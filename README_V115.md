# FinOps V115 — cartes équipe compactes et élégantes

Refonte visuelle des cartes d'équipe dans le détail de Synthèse.

## Budget équipe
Les informations Fixe / Variable / Total sont regroupées dans trois mini-KPI
compacts en tête de carte.

## ROI équipe
Le ROI est présenté dans une grille compacte à 6 indicateurs :
- RH N-1
- RH N
- Économie RH
- Coût licences
- Gain net annuel
- ROI

Il n'y a plus de badge « ROI positif » ou « ROI négatif ».
Seules les valeurs elles-mêmes utilisent une mise en évidence discrète :
- vert si le gain / ROI est positif ;
- rouge si le gain / ROI est négatif.

Le rendu HTML utilise la même structure et la même hiérarchie visuelle.

Aucune migration Grist ni réconciliation ACL n'est nécessaire.
